# History of OOP

## Introduction

Object-Oriented Programming evolved to solve the limitations of procedural programming.

---

## Timeline

| Language | Year |
|----------|------|
| Simula | 1967 |
| Smalltalk | 1972 |
| C++ | 1985 |
| Python | 1991 |
| Java | 1995 |
| C# | 2000 |

---

## Simula (1967)

- First OOP language
- Introduced classes and objects

---

## Smalltalk (1972)

- Fully object-oriented language
- Popularized OOP concepts

---

## C++ (1985)

Created by:

**Bjarne Stroustrup**

Features:

- Classes
- Inheritance
- Polymorphism

---

## Java (1995)

Developed by Sun Microsystems.

Principle:

```
Write Once, Run Anywhere
```

---

## Python (1991)

Simple and beginner-friendly OOP language.

---

## Importance of OOP History

Understanding the evolution of OOP helps explain why modern programming languages use object-oriented concepts.

---

## Interview Questions

### Who invented C++?

### Which was the first OOP language?

### Which language popularized OOP?

Smalltalk.

## Summary

OOP evolved from Simula and became popular through C++, Java, and Python.
