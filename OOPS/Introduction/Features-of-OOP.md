# Features of Object-Oriented Programming

## Main Features

### 1. Class

Blueprint for objects.

---

### 2. Object

Instance of a class.

---

### 3. Encapsulation

Wrapping data and methods together.

---

### 4. Abstraction

Hiding implementation details.

---

### 5. Inheritance

Acquiring properties of another class.

---

### 6. Polymorphism

One interface with multiple behaviors.

---

### 7. Dynamic Binding

Function call determined at runtime.

---

### 8. Message Passing

Objects communicate using functions.

---

### 9. Reusability

Code can be reused using inheritance.
