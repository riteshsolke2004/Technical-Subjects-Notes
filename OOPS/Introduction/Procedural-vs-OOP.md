# Procedural Programming vs Object-Oriented Programming

## Procedural Programming

Program is divided into functions.

Example:

- C language

---

## Object-Oriented Programming

Program is divided into classes and objects.

Example:

- C++
- Java
- Python

---

## Comparison Table

| Feature | Procedural | OOP |
|----------|------------|-----|
| Approach | Top Down | Bottom Up |
| Focus | Functions | Objects |
| Security | Low | High |
| Reusability | Less | High |
| Maintenance | Difficult | Easy |
| Data Hiding | No | Yes |

---

## Procedural Example

```cpp
int balance = 1000;

void withdraw() {
    balance -= 100;
}
```

---

## OOP Example

```cpp
class Bank {
private:
    int balance;

public:
    void withdraw() {
        balance -= 100;
    }
};
```

---

## Advantages of OOP over Procedural Programming

- Better Security
- Easier Maintenance
- Reusability
- Modularity

---

## Interview Questions

### Which language mainly follows procedural programming?

C language.

### Which approach is used in OOP?

Bottom-Up Approach.

## Summary

OOP is more suitable for large and complex applications.
