# Why OOP?

## Need for OOP

As software projects became larger, procedural programming faced several problems.

OOP was introduced to solve these issues.

---

## Problems in Procedural Programming

### 1. Code Duplication

Same code must be written repeatedly.

### 2. Poor Security

Global variables can be modified by anyone.

### 3. Difficult Maintenance

Large programs become hard to manage.

### 4. Low Reusability

Existing code cannot be reused efficiently.

### 5. Complex Debugging

Errors are difficult to find.

---

## Why OOP is Better?

OOP provides:

- Encapsulation
- Abstraction
- Inheritance
- Polymorphism

---

## Benefits of OOP

### Code Reusability

Inheritance reduces duplicate code.

### Data Security

Private members protect data.

### Easy Maintenance

Changes affect fewer components.

### Better Organization

Programs are divided into classes.

### Scalability

Large projects become easier to manage.

---

## Real World Example

Banking System

Instead of storing everything globally:

```cpp
balance = 10000;
```

We encapsulate it:

```cpp
class BankAccount {
private:
    int balance;
};
```

This improves security.

## Interview Questions

### Why was OOP introduced?

To overcome the limitations of procedural programming.

### Why is OOP preferred for large projects?

Because it provides modularity, security, and reusability.

OOP makes programs:
